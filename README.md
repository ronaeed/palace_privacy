# Palace privacy policy

The privacy policy for **Palace: Classic Shed Card Game** (Android package `com.anoragames.palace`), by Anora Games.

The page is `index.html` in the repo root. GitHub Pages serves the `main` branch root (Settings › Pages › Deploy from a
branch), at https://ronaeed.github.io/palace_privacy/. That URL goes in Play Console.

To change the policy: edit `index.html`, update the effective date, and push.
