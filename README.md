# Palace privacy policy

The privacy policy for **Palace: Classic Shed Card Game** (Android package `com.anoragames.palace`), by Anora Games.

The page lives in `site/index.html`. Every push to `main` publishes it to GitHub Pages
(`.github/workflows/pages.yml`), at https://ronaeed.github.io/palace_privacy/. That URL goes in Play Console.

To change the policy: edit `site/index.html`, update the effective date, and push.
